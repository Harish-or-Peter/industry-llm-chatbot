# 🧠 Industry-Specific LLM Chatbot

## 📌 Overview

This project builds a domain-specific chatbot using a fine-tuned Large Language Model (FLAN-T5). The chatbot is designed to handle industry-specific queries with contextual accuracy.

## 🎯 Objective

To develop an intelligent conversational AI system that can understand and respond to user queries within a specific industry.

## 🏭 Industry

Retail Banking

## 📂 Dataset

* Bitext Retail Banking Dataset
* Preprocessed and cleaned
* Train-test split applied

## 🤖 Model

* FLAN-T5 Small
* Fine-tuned using Hugging Face Transformers

## ⚙️ Training Details

* Platform: Google Colab
* Epochs: 3
* Batch Size: 4

## 💬 Features

* Context-aware responses
* Handles real-world queries
* Interactive UI using Gradio
